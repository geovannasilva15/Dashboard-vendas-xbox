# Dashboard Xbox Game Pass

Dashboard desenvolvido em Microsoft Excel para transformar dados de assinaturas em uma visão executiva de vendas e desempenho.

## Indicadores analisados

- receita total e evolução mensal;
- total de assinantes;
- ticket médio;
- renovação automática;
- receita por plano e tipo de assinatura;
- adesão e receita de passes adicionais.

## Organização da planilha

| Aba | Conteúdo |
|---|---|
| Base | Dados tratados e estruturados |
| Cálculos | Indicadores e tabelas auxiliares |
| Dashboard | KPIs e visualizações |
| README | Orientações dentro do arquivo |

## Visualizar

1. Baixe [dashboard_vendas_xbox_game_pass.xlsx](dashboard_vendas_xbox_game_pass.xlsx).
2. Abra o arquivo no Microsoft Excel.
3. Acesse a aba **Dashboard**.
